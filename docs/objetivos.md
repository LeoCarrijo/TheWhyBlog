# Objetivos do blog

- Documentar desenvolvimento do "TheWhyGame";
- Praticar desenvolvimento web;
- Criar registro público de meu progresso no desenvolvimento do jogo.

# Páginas

## 1 - Página inicial

Deverá conter uma breve apresentação, como:
 - Apresentação minha;
 - Apresentação do jogo atual;
 - Relatório mais recente;
 - Links para as demais seções do blog.

## 2 - Devlog

Aqui nessa página ficarão os .md que serão os registros de desenvolvimento no seguinte formato:
- Devlog #1 - O início do projeto
- Devlog #2 - Criando a movimentação do personagem
- Devlog #3 - Meus primeiros sprites no Aseprite
- ...

## 3 - Jogo

Inicialmente, ela deve conter:
- Nome do jogo;
- Breve descrição;
- Objetivo do jogador;
- Screenshots;
- Tecnologias utilizadas;
- Status atual do desenvolvimento.

## 4 - Sobre

Deverá ser uma página falando sobre mim, não necessariamente algo muito profissional, mas algo como:

> Sou técnico em TI e formado em Análise e Desenvolvimento de Sistemas. Este espaço é onde documento meus projetos, estudos e experiências com desenvolvimento de jogos e tecnologia.
